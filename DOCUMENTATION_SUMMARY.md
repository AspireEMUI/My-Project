## 🔐 Security & Backups

### Backup Strategy
```
Before making changes:
1. Save copy: script.js.backup
2. Save copy: script.js.backup2
3. Make changes to: script.js
4. Test thoroughly
5. If problems: Restore from backup
```

### Version Control (Git)
```
Use Git to track changes:
git init
git add .
git commit -m "Initial commit"

Then:
- Every change is tracked
- Easy to rollback
```
