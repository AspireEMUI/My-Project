## 🚨 TROUBLESHOOTING (If Something Goes Wrong)

### Site Won't Deploy
```
Error: "Deployment failed"
→ Check internet connection
→ Try again: bash deploy-netlify.sh
→ Or manually drag folder to Netlify

Error: "Command not found"
→ May not have Netlify CLI installed
→ Go to DEPLOYMENT_GUIDE.md for manual upload
→ Or use Vercel instead (deploy-vercel.sh)
```

### Site Looks Broken Live
```
Problem: Images don't show
→ Check DevTools Network tab
→ Verify image URLs are public
→ Wait 5 minutes for cache clear

Problem: Styling looks wrong
→ Force refresh: Ctrl+Shift+R
→ Check `:root` colors in styles.css
→ Clear browser cache

Problem: Cart doesn't work
→ Check console for JavaScript errors
→ Verify script.js loaded
→ Try in incognito mode
```

### No Traffic/Visitors
```
Normal! First day is usually quiet.
→ Keep promoting on social media
→ Share more posts
→ Ask friends to visit
→ Traffic builds over days, not hours
```

### Newsletter Not Working
```
Check: Is form submitting?
→ Open console → Look for errors
→ Try submitting test email
→ Check email service (Mailchimp, etc.)

If not receiving emails:
→ Check spam folder
→ Verify email address
→ Check email service logs
```
