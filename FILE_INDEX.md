## 🚀 The Simplest Path to Launch

```
1. Open QUICK_START.md
2. Open cosmetics-landing.html in text editor
3. Change brand name (search for "Lumineux")
4. Change colors in styles.css (find :root)
5. Replace image URLs with your images
6. Drag HTML to browser to test
7. Go to Netlify.com → New site from Git
8. Push your files to GitHub
9. Click deploy
10. Done! Your site is live
```

**Total time: ~30 minutes**
