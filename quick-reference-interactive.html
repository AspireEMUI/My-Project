⚡ Add Product in 5 Minutes

Step 1: Prepare Image (1 min)

Save your product image to: /images/NN-product-name.jpeg
Example: /images/10-vitamin-c-serum.jpeg

Step 2: Open script.js (30 sec)

• Find line 5: const productsDatabase = [
• Scroll to the end (before ];)

Step 3: Add Product Code (2 min)

{
    id: 'YOUR-ID',
    name: 'Your Product Name',
    category: 'Category',
    price: 999,
    badge: 'New',
    description: 'Short description here.',
    mainImage: 'images/NN-product-name.jpeg',
    additionalImages: ['images/NN-product-name.jpeg'],
    features: ['Feature 1', 'Feature 2', 'Feature 3'],
    sizes: ['50ml', '100ml'],
    rating: { stars: 5, count: 0 },
    isNew: true,
    isActive: true,
    displayOrder: 10
}

Step 4: Don't Forget the Comma! (30 sec)

⚠️ If there's a product BEFORE yours, add a comma after it: 
    },  // ← This comma
    {
        id: 'your-new-product',
        ...
    }

Step 5: Save & Reload (30 sec)

✅ Save the script.js file
✅ Reload your browser
✅ Your product appears!

⚡ Common One-Line Changes

Change Price

price: 1250,  // ← Change this number

Make it New

isNew: true,  // ← Change from false to true

Hide Product

isActive: false,  // ← Change from true to false

Add "New" Badge

badge: 'New',  // ← Change from null to 'New'

Add Best Seller Badge

badge: 'Best Seller',  // ← Change from null

Change Category

category: 'Skincare',  // ← Change to your category

Update Rating

rating: { stars: 5, count: 500 },  // ← Change both numbers

Reorder Product

displayOrder: 5,  // ← Lower numbers = appear first

📝 Property Reference

Property Format Example Rules
id lowercase-hyphenated vitamin-c-serum Must be unique
name Title Case Vitamin C Serum Required
category 1-2 words Serums Required
price Number only 1250 No Rs., no commas
badge 'New', 'Best Seller', 'Popular', null 'New' Optional
description 1-2 sentences Natural serum... Required
mainImage images/filename.jpeg images/10-serum.jpeg Must exist
additionalImages Array of paths ['images/10-serum.jpeg'] At least 1
features Array 2-4 items ['Natural', 'Fast'] Required
sizes Array of strings ['50ml', '100ml'] At least 1
rating { stars: 1-5, count: number } { stars: 5, count: 248 } Required
isNew true or false true Required

🌳 Quick Decision Tree

Want to...? ├─ Change price? │ └─ Change: price ├─ Make it New? │ └─ Change: isNew to true │ └─ Optionally change: badge to 'New' ├─ Add "Best Seller" badge? │ └─ Change: badge to 'Best Seller' ├─ Hide product? │ └─ Change: isActive to false ├─ Show it again? │ └─ Change: isActive to true ├─ Reorder it? │ └─ Change: displayOrder ├─ Update description? │ └─ Change: description ├─ Change image? │ └─ Change: mainImage to new image path ├─ Add gallery images? │ └─ Change: additionalImages to array ├─ Update rating? │ └─ Change: rating { stars: X, count: Y } ├─ Add new features? │ └─ Change: features array └─ Add new sizes? └─ Change: sizes array

✅ Validation Checklist

Before saving, verify:

  • Product id is unique (not used before)
  • Product id is lowercase with hyphens
  • Product id has no spaces
  • name is present (required)
  • category is present (required)
  • price is a number (not text)
  • badge is 'New', 'Best Seller', 'Popular', or null
  • description is 1-2 sentences
  • mainImage path exists in /images/ folder
  • additionalImages includes at least mainImage
  • features has 2-4 items
  • sizes has at least 1 item
  • rating.stars is 1-5
  • rating.count is a number
  • isNew is true or false
  • isActive is true or false
  • displayOrder is a number 1-99
  • Comma after product (except last product)
  • No syntax errors (check browser console)

🆘 Emergency Checklist

Page Breaks After Editing

  1. Open browser console (F12 → Console tab)
  2. Look for error message with line number
  3. Check for:
    • Missing comma after product object
    • Missing or mismatched braces {}
    • Mismatched quotes ' or "
    • Incomplete string values
  4. Fix the error
  5. Save file
  6. Reload page

Product Doesn't Appear

  1. Check isActive: true
  2. Check displayOrder: X (number 1-99)
  3. Check product id is unique
  4. Check all required fields present
  5. Reload page (hard refresh: Ctrl+F5)

Image Doesn't Load

  1. Check file exists in /images/ folder
  2. Check filename is exactly correct (case-sensitive)
  3. Check path format: 'images/filename.jpeg'
  4. Check file extension: .jpeg or .png
  5. Reload page

💡 Tips & Tricks

Tip 1: Use Gaps in displayOrder

Instead of 1, 2, 3, use 10, 20, 30, 40...

// Good structure:
displayOrder: 10
displayOrder: 20
displayOrder: 30

// Later, add new product easily:
displayOrder: 25  // Fits between 20 and 30

Tip 2: Template-Based Workflow

  1. Copy an existing similar product
  2. Change the id, name, and other properties
  3. Save and test
  4. Adjust as needed

Tip 3: Test One at a Time

  1. Add one product
  2. Save and reload
  3. Verify it appears
  4. Add next product
  5. Repeat

Tip 4: Keep Backups

Before making major changes, save a copy of script.js:

script.js.backup
script.js.backup2

This way you can revert if something goes wrong!
