# Frequently Asked Questions (FAQ)

Common questions and answers about the Lumineux Beauty landing page template.

## Installation & Setup

### Q: Do I need to install anything?
**A:** No! This is a static HTML/CSS/JavaScript site. Just open `cosmetics-landing.html` in any browser. No build tools, frameworks, or server required.

### Q: How do I open the HTML file?
**A:** 
- Windows: Double-click `cosmetics-landing.html`
- Mac: Double-click or right-click → Open With → Browser
- Or drag the file into your browser window

### Q: Can I edit the files on my computer?
**A:** Yes! Use any text editor (VS Code, Notepad++, Sublime, etc.). Save and refresh your browser to see changes.

### Q: Is this compatible with my hosting provider?
**A:** Yes! Works with any hosting provider that serves static files (Netlify, Vercel, shared hosting, VPS, etc.).

## Customization

### Q: How do I change the brand color?
**A:** Edit `styles.css`, find the `:root` section at the top, and change the hex codes:
```css
--primary: #d4a5a5;  /* Change this to your color */
```
Save and refresh your browser.

### Q: How do I add my own products?
**A:** Duplicate a product card in `cosmetics-landing.html`:
1. Find a `.product-card` div
2. Copy the entire `<article class="product-card">...</article>` block
3. Paste it again in the same section
4. Update the image URL, name, price, description
5. Save and refresh

### Q: Can I change the fonts?
**A:** Yes! In `styles.css`, find this section:
```css
@import url('https://fonts.googleapis.com/css2?family=Playfair+Display&display=swap');
```

Replace with your own Google Font link, then update:
```css
--font-display: 'Your Font Name', serif;
--font-body: 'Your Font Name', sans-serif;
```

### Q: How do I add more sections?
**A:** Copy an existing `<section>` tag in the HTML, modify the content and styling. Keep the same class structure and it should integrate seamlessly.

## Functionality

### Q: Why isn't the shopping cart saving?
**A:** 
1. Make sure JavaScript is enabled in browser settings
2. Check browser console (F12) for errors
3. Verify `script.js` file is in same directory as HTML
4. Clear browser cache (Ctrl+Shift+Delete) and reload

### Q: How do I connect the newsletter form?
**A:** 
1. For Mailchimp: Get embed code from audience settings, replace form
2. For ConvertKit: Add script tag to `<head>` with your ID
3. For custom: Update `handleNewsletterSubmit()` function in `script.js`

See CUSTOMIZATION_GUIDE.md for detailed instructions.

### Q: How do I add payment processing?
**A:** Update the "Proceed to Checkout" button in the cart modal:
```javascript
// In script.js, modify renderCartItems() function:
<button class="cta-primary" onclick="window.location.href='YOUR_PAYMENT_URL'">
```

Or integrate Stripe/PayPal using their SDKs. See CUSTOMIZATION_GUIDE.md.

### Q: Can I add a contact form?
**A:** Yes! Create a new section with form HTML and add a handler in `script.js`:
```javascript
function handleContactSubmit(event) {
    event.preventDefault();
    // Send to your backend or service
}
```

### Q: How do I enable dark mode?
**A:** Dark mode is already implemented! It activates automatically based on OS settings. Users can toggle via their device settings. No code changes needed.

## Performance & Optimization

### Q: How do I speed up my site?
**A:**
1. Optimize images (< 200KB each) using TinyPNG or Squoosh
2. Use WebP format instead of JPEG when possible
3. Enable gzip compression on your server
4. Minimize CSS/JS for production
5. Use a CDN for images (Cloudflare, Imgix, Cloudinary)

### Q: How can I improve performance further?

1. Run Lighthouse audit: F12 → Lighthouse
2. Follow recommendations
3. Test with GTmetrix

## SEO & Marketing

### Q: How do I improve SEO?
**A:** 
1. Update meta title and description (< 160 chars)
2. Write keyword-rich alt text for images
3. Use proper heading hierarchy (h1 → h2 → h3)
4. Add schema.org markup for products
5. Submit to Google Search Console
6. Create XML sitemap (auto-generated by hosting)

### Q: How do I track visitors?
**A:** 
1. Set up Google Analytics (free)
2. Get Measurement ID
3. Add GA4 script to `<head>`
4. Wait 24 hours for data
5. Monitor dashboard

### Q: How do I enable social sharing?
**A:** Add Open Graph meta tags (already included). Update with your images:
```html
<meta property="og:image" content="your-image-url">
```

### Q: How do I add a blog?
**A:** Create `/blog` folder with similar HTML structure. Use same CSS for consistency. Consider static site generator (Hugo, Jekyll) for managing multiple posts.

## Accessibility

### Q: Is this accessible?
**A:** Yes! WCAG AA compliant with:
- Color contrast 4.5:1+
- Keyboard navigation
- Screen reader support
- Dark mode
- Reduced motion support

### Q: How do I test accessibility?
**A:**
1. Keyboard: Tab through entire page
2. Screen reader: NVDA (Windows) or VoiceOver (Mac)
3. Contrast: WebAIM Contrast Checker
4. Automated: WAVE tool

### Q: How do I add aria-labels?
**A:** Add to any interactive element:
```html
<button aria-label="Open shopping cart">🛒</button>
```

## Troubleshooting

### Q: My images aren't showing
**A:**
1. Check image URL is correct and public
2. Open URL directly in browser to verify
3. Check file permissions on server
4. Check for CORS errors in console (F12)
5. Try uploading to CDN (Cloudinary, Imgix)

### Q: Cart doesn't persist after refresh
**A:**
1. Check browser allows localStorage: F12 → Application → LocalStorage
2. Clear site data and reload
3. Try incognito mode to verify
4. Check localStorage quota (usually 5-10MB)

### Q: Form emails aren't being received
**A:**
1. Check email service is configured
2. Verify API endpoint in code
3. Check spam/junk folder
4. Verify sender email address is authorized
5. Check service logs/dashboard

### Q: Site looks broken on mobile
**A:**
1. Check viewport meta tag: `<meta name="viewport" content="width=device-width">`
2. Clear browser cache
3. Test in multiple browsers
4. Check CSS media queries
5. Verify images scale properly

### Q: JavaScript errors in console
**A:**
1. Open F12 → Console
2. Note the error message and line number
3. Check file path in script tags
4. Verify `script.js` location
5. Check for syntax errors

### Q: Forms submitting but nothing happens
**A:**
1. Check browser console for errors
2. Verify onsubmit handler exists
3. Check API endpoint is correct
4. Verify CORS settings
5. Check email service configuration
